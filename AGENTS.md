# AGENTS.md

## Projeto

Este repositório contém a página oficial de link na bio da marca TykaYurt.

## Arquivo principal

O código da aplicação está em:

- `index.html`

Esse arquivo contém HTML, CSS e JavaScript da página. Não existe framework, bundler ou etapa de build.

## Asset local

- `logo-tykayurt.png` — logo exibido no topo da página.
- `images/` — imagens locais dos sabores exibidas nos cards.

## Como executar

Use:

```bash
npm install
npm run dev
```

A aplicação ficará disponível em `http://localhost:3000`.

Também pode ser aberta diretamente pelo arquivo `index.html`.

## Regras ao editar

- Preservar o layout mobile-first de link na bio.
- Preservar a identidade visual TykaYurt.
- Usar Anton para títulos e Manrope para textos.
- Não adicionar frameworks sem necessidade.
- Manter os cards grandes empilhados.
- Manter responsividade para telas de celular.
- Preservar `prefers-reduced-motion`.
- Não remover os links configurados sem solicitação explícita.
